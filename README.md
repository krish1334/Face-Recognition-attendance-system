# 🎓 Face Recognition Attendance System

A Python-based **Face Recognition Attendance System** that automatically marks attendance using facial recognition technology.  
This project eliminates manual attendance, reduces proxy attendance, and improves accuracy using computer vision.

---

## 📌 Features
- Automatic face detection and recognition
- Real-time attendance marking
- Stores attendance records digitally
- Easy to use and scalable
- Reduces manual effort and errors

---

## 🛠️ Tech Stack
- **Programming Language:** Python  
- **Libraries & Tools:**
  - OpenCV
  - face_recognition
  - NumPy
  - Pandas
- **IDE:** VS Code / PyCharm  
- **Version Control:** Git & GitHub  

---

## ⚙️ How It Works
1. The system captures images using a webcam.
2. Facial features are extracted and encoded.
3. The captured face is compared with stored images.
4. If a match is found, attendance is marked with:
   - Name
   - Date
   - Time
5. Attendance is stored in a CSV/Excel file.
